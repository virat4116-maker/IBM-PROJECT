# Sales Performance Dashboard & EDA (Pandas)

## Project files
- `Sales_Dataset.csv` — illustrative transaction dataset (240 rows, Jan–Dec 2025).
- `Sales_Performance_EDA.ipynb` — Jupyter Notebook containing the complete Pandas EDA workflow.
- `Sales_Performance_EDA.py` — companion Python script for running the analysis.
- `Sales_Performance_Dashboard_Presentation.pptx` — project presentation.

## How to run
1. Install Python 3.
2. Install dependencies: `pip install pandas matplotlib jupyter`
3. Keep `Sales_Dataset.csv` and `Sales_Performance_EDA.ipynb` in the same folder.
4. Open Jupyter Notebook and run all cells from top to bottom.

## Analysis included
- Dataset inspection and data cleaning
- KPI calculations: sales, profit, orders, units sold and profit margin
- Category-wise and region-wise sales analysis
- Monthly sales trend
- Top 10 products by sales
- Business insights and conclusion

## Dataset note
The dataset is synthetic sample data created for academic demonstration; it is not actual company data.
