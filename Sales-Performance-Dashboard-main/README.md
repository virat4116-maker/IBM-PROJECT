# Sales Performance Dashboard — IBM Cognos Analytics

Academic dashboard project using a synthetic sales dataset.

## Project contents
- `Sales_Dataset.csv` — source data for importing into IBM Cognos Analytics.
- `Sales_Performance_Dashboard.xlsx` — Excel workbook containing a dashboard preview, dataset sheet, and Read Me sheet.
- `COGNOS_BUILD_GUIDE.md` — steps and field mappings for recreating the dashboard in Cognos.

## Dataset
- 240 order records covering January–December 2025.
- Fields: Order ID, Order Date, Region, Category, Product, Quantity, Sales, Profit, Month.
- Total Sales: 468,017.67
- Total Profit: 131,342.54
- Total Orders: 240
- Units Sold: 1,552

**Data note:** This is synthetic illustrative data created for an academic practical. It does not represent a real company.

## Important submission note
The Excel workbook includes a dashboard preview/reference. It is **not** a native IBM Cognos dashboard. To submit an actual Cognos dashboard, import `Sales_Dataset.csv` into your Cognos Analytics workspace, build the visualizations using the guide, and save/share the dashboard from Cognos.
